\# Employee Management System



A console-based Employee Management System developed using Core Java as a learning project.



\## Features



\- Add employees

\- View all employees

\- Find employees by ID

\- Update employee details

\- Delete employees

\- Menu-driven console interface

\- Input validation and exception handling (as implemented)



\## Technologies Used



\- Java

\- Core Java fundamentals

\- Eclipse IDE

\- Git and GitHub



\## Project Structure



```text

EmployeeManagementSystem/

├── src/

│   └── Main.java

├── .classpath

├── .project

├── .gitignore

└── README.md

```



\## How to Run



1\. Clone or download this repository.

2\. Import the project into Eclipse as an existing Java project.

3\. Open `src/Main.java`.

4\. Run the `Main` class as a Java application.



Alternatively, compile and run from the project directory using a JDK:



```bash

javac -d bin src/Main.java

java -cp bin Main

```



\## Learning Goals



This project is intended to practice Java programming, console input/output, control flow, and object-oriented programming as the application develops.
